# Brainmeat

*Author*: Alexander Cote

## Deploy

No extra deployment is necessary. Just upload `brainmeat.txt`.

## How to build (Not necessary for deployment)

1. Compile `generate_scramble.c`.
2. Run the compiled program with the input code (`flag.bf`) and a file containing filler text (`random.txt`). The scrambled output will be printed to `stdout`.
